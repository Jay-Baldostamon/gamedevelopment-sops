## Prerequisites

- [ ] Confirm whether the request is for active async standups or historical reporting reference.
- [ ] Open the active standups playbook before performing current reporting operations.
- [ ] Open the Team Lead absence coverage SOP before performing absence or backup operations.

IF the request concerns absence, backup, or meeting coverage operations, THEN use `docs/playbooks/planning-and-reporting/Team Lead Absence Coverage.md` and do not use this archived reporting workflow.

## Step-by-Step Checklist

### Phase 1: Route active work

1. **Route active daily standup work** to `docs/playbooks/planning-and-reporting/Engineering Standups via Slack.md`.
2. **Route absence and backup work** to `docs/playbooks/planning-and-reporting/Team Lead Absence Coverage.md`.
3. **Use this archived playbook only** when reviewing historical reporting guidance.

IF a requester asks to execute the retired reporting workflow, THEN direct them to the applicable active playbook before proceeding.

- [ ] Active work is routed to a current playbook.
- [ ] Historical reference use is clearly labeled as archival.

### Phase 2: Preserve archival context

4. **Retain this document** as a deprecated record rather than an active operating procedure.
5. **Avoid copying legacy reporting requirements** into active workflows without Engineering Department Leadership review.

IF historical guidance conflicts with an active playbook, THEN follow the active playbook.

- [ ] The deprecation status is clear.
- [ ] No active absence or backup process is governed by this document.
