This timeline takes a backend engineer from L1 (executing predefined tickets) to performing at L2 (autonomously scoping and delivering solutions), as measured by the gates in `docs/career-ladder/backend/L1 to L2 Promotion Gate.md`.

The program is a **skills mastery path driven by evidence**, not a "how to get promoted" playbook. Every week maps to a gate (G1–G5) or blocking gate (B1–B3) from the promotion gate document, so the skills learned are exactly the skills that promotion evidence measures.

## Timeline Summary

The program runs 13 weeks (~90 working days) across three months. Each week owns one skill focus and produces gate evidence.

- Month 1 — Autonomy Foundations (Weeks 1–4): decompose and deliver bounded work independently.
- Month 2 — Data Layer & Full Stack (Weeks 5–8): own the data layer and deliver complete features.
- Month 3 — Operations, Quality, Mentorship (Weeks 9–13): own uptime, deployments, review, and others' progress.

## Progressive Gate Matrix

| Phase | Weeks | Gate focus | Blocking threshold (this phase) | Objective |
| :-- | :-- | :-- | :-- | :-- |
| Month 1 | 1–4 | G1, start G3 | ≥3 feature decompositions accepted by a Senior; ≥1 feature delivered end-to-end with tests | Shift from executing tasks to scoping and delivering bounded work |
| Month 2 | 5–8 | G2, deepen G3 | ≥2 migration PRs merged nondestructively; ≥2 full-stack features with test coverage | Deliberately design and own the data layer |
| Month 3 | 9–13 | G4, G5, B1–B3 | ≥2 rollouts owned; ≥1 clean rollback; ≥4 consecutive weeks at 3–4 Project Units; no pipeline or honesty violations | Own uptime, deployment, review, and unblocking |

## Month-by-Month Focus

### Month 1 — Autonomy Foundations

- Week 1: Decomposition Independence (G1)
- Week 2: Scoped Full-Stack Sprint (G3)
- Week 3: AI Velocity & Ownership (G3)
- Week 4: Consolidation & G1 Gate (G1)

### Month 2 — Data Layer & Full Stack

- Week 5: Schema Design & Non-Destructive Migration (G2)
- Week 6: Query Performance (G2, G3)
- Week 7: Multi-Step Transactional Flow (G3)
- Week 8: Consolidation & Data-Layer Re-Run (G2, G3)

### Month 3 — Operations, Quality, Mentorship

- Week 9: Production Debugging (G4, B3)
- Week 10: Deployment Ownership & Rollback (G4, B3)
- Week 11: PR Review & Security Surface (G2, B1)
- Week 12: Technical Pushback & Mentorship (B2)
- Week 13: Ownership Capstone (all gates)

## Guiding Principle

Progression is earned through verifiable gate evidence over an 8-week observation window, not through elapsed time or task completion alone. A week that produces no artifact tied to a promotion gate does not count toward L2 readiness.
