Week 13 is the ownership capstone: one complete independent cycle — decompose → build → ship → deploy → monitor → (rollback if needed) — plus one documented P2 resolution or rollback, one mentorship, and a final self-audit against the promotion gate matrix. This is the rehearsal for L2.

## What to Expect This Week

- **Day 1:** Capstone scoping. Choose a real feature that requires a schema change and a migration. Write the five-part decomposition; confirm scope with the Senior. No step-by-step guidance from here on.
- **Day 2:** Build + test. Implement the full-stack feature with test coverage (primary path + boundary + failure path), keeping the B1 pipeline discipline.
- **Day 3:** Review + deploy. Open the PR, address review, and — given green checks and authority — initiate the deployment through the standard pipeline and monitor post-deploy metrics.
- **Day 4:** Operations + mentorship day. Handle any live P2/P3 on an assigned unit (documented) OR execute the documented rollback if metrics degraded; run an L1 unblock if one escalates.
- **Day 5:** Final gate audit. Complete the promotion gate matrix self-assessment against the gate document; assemble the evidence set (decompositions, migrations, features, rollouts, rollback, incident/mentorship logs) and submit to the Senior reviewer and Engineering Manager.

## Week 13 Success Criteria

- [ ] Completed one independent decomposition → feature → deployment → monitor cycle
- [ ] Capstone feature shipped with tests through the standard pipeline (G3 + B1)
- [ ] ≥1 documented P2 resolution OR rollback executed (G4/B3)
- [ ] Executed the mentorship protocol if an L1 escalated (B2)
- [ ] Final self-audit completed against the promotion gate matrix
- [ ] Complete evidence set submitted for evaluation

## Guiding Principle

The capstone is proof, not practice. If the full cycle completes with every hard gate met and every blocking gate clean, the candidate is operating at L2 — the gate reviewers decide the promotion.
