These optional self-checks let you assess a familiar competency locally instead of repeating practice unnecessarily. No issue, recording, submission, supervisor decision, or training sign-off is required. Repeat a check or follow the corresponding daily lesson if you need more practice.

| Competency | Self-check |
| --- | --- |
| **Code Literacy** (Day 5) | Select one 50–100 line C# function or equivalent mock game-data routine. Identify where it is used and explain its logic and important calls in your own words. Verify uncertain points against the code or a focused test. |
| **Version Control** (Day 10) | Inspect at least five descriptive commits, then practice restoring a disposable file or mock-data artifact in a safe test branch and verify the restored result locally. |

The browser tracker schedules all days in order and has no separate skip control. Use its normal checklist to mark work you have completed; these optional self-checks do not automatically change tracker progress.

## Lane Coverage

Both self-checks support the **Unity gameplay lane** and the **game data lane**:

- **Code Literacy** — inspect a gameplay function or an approved mock player-data routine.
- **Version Control** — practice Git recovery with a disposable project file or mock-data artifact.
