## Unity Game-Development Track Context

This level or week uses the same desktop 2D C# action-platformer on the current Unity LTS release. The Unity gameplay lane covers scripts, scenes, prefabs, assets, tests, and builds. The former DB lane is now the game data lane for player profiles, save slots, checkpoints, collectibles, unlocks, and leaderboard contracts.

For L3/L4, scheduling, agents, and cloud workers support the Unity repository and build/test pipeline. Use only approved mock or game-specific data, not CRM or unrelated production systems. If a fixture is unavailable, identify the blocker locally and keep the work design-only. Preserve authorization, independent review for actual PRs, and secret-handling controls; no training reports or supervisor sign-offs are required.

This timeline defines the progressive path from AI-assisted fundamentals to independent execution and contribution readiness.

## Timeline Summary

The L1 training timeline runs for four weeks (20 working days) and is designed to move Engineers from guided practice into structured ownership of real engineering workflow through a dual-lane model:

- Shared Core: Days 1-3
- Lane Execution: Unity Gameplay Lane and Game Data Lane (Days 4-13, 15-18)
- Reconverged Days: Day 14, Day 19, Day 20

## Progressive Practice

| Phase | Local objective |
| --- | --- |
| Week 1 | Build AI fluency and explain a gameplay function or mock-data routine. |
| Week 2 | Practice project ownership, scope control, and safe version-control recovery. |
| Week 3 | Implement and validate a scoped task with appropriate project review controls. |
| Week 4 | Repeat the workflow and reflect locally on the next game improvement. |

## Month-by-Month Focus

### Month 1 (L1)

- Week 1: Shared AI discipline (Days 1-3) plus lane onboarding (Days 4-5)
- Week 2: Lane execution fundamentals (Unity gameplay workflow or game-data workflow with approved mock game-data evidence practices)
- Week 3: Real repository ownership by lane plus reconverged Day 14 task creation
- Week 4: Lane reinforcement (Days 16-18) plus reconverged translation/retrospective closure (Days 19-20)

## Guiding Principle

Progression is self-paced and based on completed exercises and local checks, not supervisor reporting.
