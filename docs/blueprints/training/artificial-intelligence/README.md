# Unity Game-Development Training

## Active curriculum

Use the [Tools-Only 80-Day Learning Plan](Tools-Only%2080-Day%20Learning%20Plan.md). It is the only active training material and is designed around the strict tool rule below. Earlier day blueprints, week/month overviews, and the tracker are legacy references and must not be used as exercise instructions.

## L1 purpose

[L1 Foundations (Days 1–20)](Tools-Only%2080-Day%20Learning%20Plan.md#level-1--foundations-days-120) introduces AI into an existing junior Unity developer's skill set. It does not reteach Unity or require multiplayer or advanced game systems. Small familiar gameplay tasks let you practice choosing inline completion, contextual chat, Gemini planning/review, or a direct Unity action; supplying focused context; evaluating suggestions; and verifying behavior yourself.

Growth means explaining accepted code, rejecting unsupported claims or unnecessary changes, and completing two small verified tasks. There are no chat-count targets or separate training reports.

## Strict tool rule

Use only:

- **Unity Game Engine**
- **GitHub Copilot AI** inside **VS Code** or **Visual Studio Community**
- **Gemini AI**

L1 uses only these tools; it does not require the GitHub website, a terminal, a separate source-control client, issue or project trackers, messaging tools, cloud services, automated agents, additional Unity packages, external asset tools, or the browser-local tracker.

**Level 2 exception (Days 21–40 only):** The active plan also permits local Hermes, its named Engineering SOPs skills, and GitHub with the authenticated GitHub CLI (`gh`) for the explicitly authorized L2 access, review, handoff, and delivery exercises. Follow the active plan's approval, read-only, and secret-handling boundaries; never merge, self-approve, or bypass CI. This exception does not apply to L1, L3, or L4.

Do not add tools or packages beyond the active plan's allowances. If a capability is unavailable, use the day's stated local alternative; if no permitted alternative is stated, pause and clarify the blocker rather than claiming completion.

## Project

The plan uses one continuous desktop 2D C# action-platformer in Unity. Exercises use Unity scenes, built-in objects, C# scripts, and Play Mode. Notes and checklists are optional Markdown files edited in the chosen IDE. Do not share secrets or confidential project information with either AI.
